# Neko Nine

スマートフォン横画面向けブラウザゲーム。

## GitHub Pages
このフォルダの中身をリポジトリ直下へアップロードし、GitHub Pages を有効にしてください。
`index.html` がそのまま起動ページです。

## 対応
- Android Chrome
- iPhone Safari
- PC Chrome / Edge
- 本番は横画面を前提
- PWA manifest / Service Worker 対応

## 注意
iPhone Safari はブラウザ仕様上、画面向き固定やフルスクリーン動作がAndroidと完全には同一にならない場合があります。
